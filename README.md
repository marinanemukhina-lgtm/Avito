# Кабинет продавца · 0.2

Неофициальный, независимый от Авито инструмент. Прототип для работы с объявлениями, а не приложение с автоматическим управлением сделками.

## Запуск без установки

Открой `index.html` в обычном браузере. Сервер, Node.js и аккаунт для этого режима не нужны. Приложение не выполняет сетевых запросов, не хранит введённые данные между загрузками и не передаёт их на Авито.

1. Выбери задачу: **объявление, сравнение цен, ответ покупателю**.
2. Заполни поля и собери черновик. Оценка использует только переданные цены объявлений (не реальные цены сделок); для медианы нужно от трёх сопоставимых позиций.
3. Исправь текст при необходимости, нажми **«Проверил(а) текст»** и скачай TXT. Если изменить исходные данные или текст, проверка сбросится.
4. При необходимости перенеси текст вручную. Выгрузка не означает публикацию или отправку.

Тексты генерируются правилами из заполненных полей, не языковой моделью. Нет поиска по всему Авито, автоматических ответов, изменения цены, публикации, снятия объявлений, заказа доставки, оплаты либо слежения. Не вводи пароли, коды входа или платёжные данные.

## Учебное демо: консультант по продажам

В верхней панели `index.html` выбери одну из трёх вымышленных карточек и нажми «Цена по прайсу», «Проверка наличия» или «Заявка менеджеру». Можно написать собственный короткий вопрос. Для демонстрационной карточки «Линия» в каталоге есть цена, а наличие не подтверждено. Если указать точное количество и один поддерживаемый город, появится только черновик заявки; бронь, сроки и отправка не подтверждаются. При смене карточки история очищается, чтобы не перенести условия между товарами.

Это локальная демонстрация правил, а не установленный ИИ-бот или коммерческий кейс. Работает на синтетических данных без LLM, входа в Авито, чтения переписки, отправки контактов, подключения Telegram и сетевых запросов. Не вставляй реальные контакты или коммерческий прайс в демо. «Проверка наличия» показывает статус выбранной карточки; цифра из учебной карточки не означает актуальный остаток.

Для рабочей версии отдельно согласовать данные поставщика, разрешённый доступ к Avito Messenger API, поиск по утверждённым прайсу и регламентам, передачу заявки оператору и проверку на тестовом аккаунте. Не использовать полные переписки из реальных аккаунтов в учебном примере.

## Опциональный адаптер официального API

Отдельный CLI для технической проверки подключения собственного профиля. **Не подключён к браузерному приложению.** Дополнительно нужен Node.js 22+ и выданные владельцу официальные клиентские данные Авито, доступные нужному аккаунту/разделу API. Адаптер использует `client_credentials` только для этого единственного профиля и запрашивает только первую страницу. Возможность использования зависит от доступа на стороне Авито; ответы успешного API содержат персональные и деловые данные, не пересылай их без разрешения.

Передай `AVITO_CLIENT_ID` и `AVITO_CLIENT_SECRET` через локальное хранилище секретов, которое подставляет переменные окружения. Не записывай значения в файлы репозитория, командную строку, историю или чат. Примеры запуска после настройки окружения:

```sh
node src/avito-read.cjs self
node src/avito-read.cjs items
node src/avito-read.cjs chats
```

Токен запрашивается у `api.avito.ru`, не возвращается командой и не сохраняется. Адаптер не редактирует профиль, ничего не публикует и не читает отдельные сообщения; `chats` запрашивает только список чатов. Автоматических повторов запросов нет. Реальный доступ не тестировался; подтверждены только синтетические тесты HTTP-контракта. См. [документацию Авито для разработчиков](https://developers.avito.ru/).

## Встраивание в NEMUKHINA SYSTEM

Ядро `src/core.cjs` экспортирует чистые функции `listing`, `price`, `reply`, `exportText`. Подключай их в отдельном модуле приложения, без переменных окружения и без адаптера. Для версии в ChatGPT результаты этих же сценариев можно использовать как черновики. Подключение оригинала аккаунта к коммерческой версии требует отдельной безопасной серверной интеграции: персональная авторизация каждого клиента, изоляция аккаунтов, секреты на сервере, явные разрешения, журнал действий без чувствительных данных, защита от повторной публикации. Многопользовательский OAuth, SaaS и доступ другим людям здесь не реализованы.

## Пересборка и проверка

```sh
node build.cjs
node --test
```

Сборка воспроизводимо генерирует переносимый HTML. npm-пакетов и стороннего исходного кода нет. Тесты не требуют сети; включены синтетическая проверка переключения состояния экспорта в собранном HTML и проверка API-адаптера с подменёнными ответами. Реальный браузер/учётная запись не проверены. Права распространения и условия коммерческого использования определяет владелец; публичная лицензия не задана.
